# Время для важного

Личный планировщик-PWA: фокус-таймер (помидор) с вопросом «чем занимался», серия дней, статистика в виде круговой диаграммы, календарь с тепловой картой, недельный обзор, дела на сегодня. Тёмная тема «Тёмная ночь», работает офлайн, устанавливается на главный экран.

Данные хранятся только на устройстве (localStorage). В настройках есть экспорт и импорт JSON.

## Запуск
Статический сайт без сборки: открыть `index.html` через любой веб-сервер (для PWA нужен HTTPS, например GitHub Pages).
